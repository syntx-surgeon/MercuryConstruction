# Mercury Construction

A sample website project for Mercury Construction company. This is a demonstration website showcasing the company's services and projects.

## Website
This is a sample website. To visit the actual company website, go to: [Mercury Construction](https://mercuryconstruction.com.np)

## Project Structure

```
├── css/
│   └── style.css
├── js/
│   └── main.js
└── fonts/
    └── woff2/
```

## Description

This is a sample web application for Mercury Construction, demonstrating a modern website design with clean structure and responsive layout. The project uses separate directories for CSS, JavaScript, and fonts to maintain organized code structure.

## Features

- Responsive design with modern CSS
- Custom font integration
- JavaScript functionality
- Sample project showcase
- Contact form demonstration

## Getting Started

1. Clone the repository
2. Open `index.html` in your web browser
3. No build process required - this is a simple static website
